\chapter{Complete Algorithm Comparison on All Senior Instances}
\label{app:algorithm-details}
\label{app:complete-algorithm-table}

This appendix gives the complete instance-level comparison of the four
implemented algorithms. \Cref{tab:appendix-complete-algo} reports the same
experiment family as \cref{tab:all-algorithms}, but for every Senior instance.
The blue instance names mark the headline instances Small, Medium, and Large.
The green cells mark the best cost and zero gap for each instance. The total
rows at the end of each algorithm block summarize the all-instance cost and
vehicle count.

One archived 5lines Senior benchmark file required a small input-format repair
before it could be used in the automated experiment workflow. The downloaded JSON copy was
structurally incomplete because the final top-level closing brace was missing.
I created a repaired working copy only by closing the JSON object. No trips,
times, costs, vehicle data, capacities, or other optimization-relevant values
were changed.
